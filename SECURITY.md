# Security

No public private-report channel exists yet. Before publication the maintainer must configure GitHub private vulnerability reporting and confirm the contact route. During this local phase notify the workspace owner directly; never post credentials or private household state in an issue.

The diagnostic client does not call tools or read resources. Tool discovery can still reveal entity names; share only its count/capability summary. Use a dedicated least-privilege Home Assistant user, restrict exposed entities, revoke test tokens when done. Public endpoint activation is outside this local phase.
