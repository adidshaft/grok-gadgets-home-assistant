# Contributing

Use Python 3.11+ and uv; run the commands in AGENTS.md. Create a short feature branch, reference a local issue, include evidence and limitations in your PR. Add behavior tests for probe changes; document source date for integration claims. Home Assistant itself owns entity control semantics.

Shared conduct and policies live in [the project hub](../grok-gadgets/CODE_OF_CONDUCT.md) and [community policies](../grok-gadgets/community/README.md), unpublished sibling references until owner selection. Original contributions use Apache-2.0. Maintainer ownership is pending GitHub owner selection; no fictitious CODEOWNERS account is declared.
